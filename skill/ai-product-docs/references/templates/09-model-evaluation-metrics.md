# 09 模型评测——评测指标

定义什么叫“好”、如何评分、如何聚合，以及达到什么门槛才能进入下一阶段。先定义指标再看结果，避免事后挑选有利口径。

## 1. 指标体系原则

- 指标必须关联 `KPI-*`、`CAP-*` 或 `REQ-*`。
- 区分门禁指标、优化指标与诊断指标。
- 质量、安全、稳定性、时延和成本至少各有明确处理方式。
- 平均分不能掩盖高风险切片；为关键切片设置单独门槛。

## 4. Judge 与人工评审

- Judge 模型、提示词、温度、输出 schema 和版本。
- 盲评、随机顺序、位置偏差控制、复评与仲裁。
- 与人工金标的校准集、相关性/一致性和抽检比例。
- Judge 失败、格式错误、超时与拒答的计分规则。

## 5. 统计与门禁

说明样本量、置信区间/显著性、重复运行次数、缺失值、异常值、成对比较和多切片比较方式。

## 6. 综合评分

只有在维度可合理加权时才计算综合分。写明归一化与权重依据，并保留各维原始分。安全红线不得被其他高分抵消。

## 7. 指标版本与变更

指标口径改变后使用新版本；历史报告不得无说明地套用新口径。

## 完成标准

- 每个指标可计算、可复现、可解释。
- 评分量表对边界例有判定规则。
- 门禁覆盖关键切片及安全红线，而非只看总平均。
